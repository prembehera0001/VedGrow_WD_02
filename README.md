# Unit Converter Web App

A responsive unit converter web application built using HTML, CSS, and JavaScript.

## Features

- Temperature conversion
- Length conversion
- Weight conversion
- Real-time result updates
- Conversion history using LocalStorage
- Clear history button
- Responsive design

## Technologies Used

- HTML
- CSS
- JavaScript
